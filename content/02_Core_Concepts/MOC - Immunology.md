# MOC - Immunology

Host defense at the host–pathogen interface — innate/adaptive immunity, vaccines, and immunopathogenesis.

**Parent:** [[Home]] · **Map:** [[Encyclopedia Map]]

## Overview

Immunology explains why the same [[Pathogen]] causes colonization in one host and lethal disease in another — and how vaccines and immune evasion shape outcomes.

## Key Subtopics
- Innate barriers, phagocytes, complement, inflammation
- Adaptive: B/T cells, antibodies, memory
- Hypersensitivity & immunopathology (e.g., post-strep sequelae)
- Vaccines: live, inactivated, subunit/conjugate, mRNA *(expand)*
- Immunodeficiency → opportunistic infection patterns
