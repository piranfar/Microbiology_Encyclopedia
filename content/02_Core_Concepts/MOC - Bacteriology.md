# MOC - Bacteriology

Classification, structure, pathogenesis, and high-yield bacterial pathogens.

**Parent:** [[Home]] · **Map:** [[Encyclopedia Map]]

## Overview

Bacteriology applies fundamentals — wall chemistry, genetics, growth — to named organisms that cause human disease. Start from Gram stain bins, then species-level virulence, diagnosis, and therapy/AMR.

## Classification Tree (clinical)

```text
Bacteria
├── Gram-positive
│   ├── Cocci
│   │   ├── Clusters → Staphylococcus ([[Staphylococcus aureus]])
│   │   └── Chains/pairs → Streptococcus / Enterococcus
│   │       ([[Streptococcus pyogenes]], [[Streptococcus pneumoniae]])
│   └── Rods
│       ├── Spore-forming → Bacillus, Clostridium / Clostridioides
│       └── Non-spore → Listeria, Corynebacterium, …
└── Gram-negative
    ├── Cocci → Neisseria, Moraxella
    ├── Enterobacterales → [[Escherichia coli]], [[Klebsiella pneumoniae]], Salmonella, …
    ├── Non-fermenters → [[Pseudomonas aeruginosa]], Acinetobacter
    ├── Curved/spiral → Vibrio, Campylobacter, Helicobacter, spirochetes
    └── Fastidious / special → Haemophilus, Legionella, Bordetella
Atypicals / special walls
├── Mycobacterium (acid-fast)
├── Mycoplasma (no wall)
├── Chlamydia / Chlamydophila
└── Rickettsia / related
```
